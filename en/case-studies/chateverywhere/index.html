Case Study #2

A clear, modern website for ChatEverywhere

We designed and built a clear, modern website for ChatEverywhere to showcase their web app, highlight key features, share weekly updates and promote live webinars. Written for teachers first, the site uses a clean layout and clear calls to action so schools can quickly understand ChatEverywhere and get started.
